# Agent instructions

Before inspecting or changing this project, read `wilibsp/AGENTS.md` completely
through EOF. If a tool truncates the file, continue reading it in chunks from
the last line until EOF; never treat the first chunk as the complete contract.
It defines the FreeWili 2 application contract, hardware invariants, build
workflow, and verification language that apply to this repository.

This application is distributed as a loadable DISPLAY-CPU UF2. Keep its release
artifact, metadata, HOME-hold recovery path, and on-device About information in
sync when changing the application.
